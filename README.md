# Judith's Archive

My Safta (grandmother), Judith Orloff, Ed.D., passed away after spending over forty years developing programs in personal transformation, leadership development, and experiential learning. She did some really incredible work, and most of it existed only as paper documents in filing cabinets and boxes.

My Saba (grandfather) and I digitized all of her work and built this archive so people can explore it. I'm also very interested in AI, so I custom-built an agentic retrieval-augmented generation (RAG) chat that lets you ask questions about Judith's writings and get answers grounded in the actual documents.

Live at [judithorloff.org](https://judithorloff.org)

If you're curious how everything works under the hood, [ARCHITECTURE.md](ARCHITECTURE.md) walks through the retrieval system, conversation storage, streaming, and cost structure in detail. [SECURITY.md](SECURITY.md) covers how the site is protected.

I hope some people find this useful, whether as a way to learn about Judith's work or as a reference for building something similar.
